# Proyecto Fútbol

Mi primer proyecto en Python: un programa que muestra el marcador de un partido y dice quién ganó.

## Qué usé

- Python
- Entorno virtual (venv)
- Git y GitHub

## Cómo ejecutarlo

1. Descarga el proyecto.
2. Crea y activa el entorno virtual.
3. Instala las librerías: `pip install -r requirements.txt`
4. Ejecuta: `python marcador.py`
